경기를 이해하고 다음 선택을 생각하세요.

Primary Rugby League의 일부 규칙과 코칭 상황을 공부하는 독립적인 영어 지식 연습 앱입니다. 해설을 읽고 유용한 문항을 다시 보며 학습 진도를 기기에 기록합니다.

앱 화면과 학습 콘텐츠는 영어입니다. 이 웹사이트는 5개 언어로 안내합니다.

럭비 지식을 차분히 복습하는 흐름

지식 학습 전용입니다. 코칭 자격, 실기 평가, 부상 진단, 경기 복귀 판단이나 경기장 안전 승인을 제공하지 않습니다.

연습 문항 500개

앱에 포함된 학습 자료의 수입니다. 공식 시험 문제은행이나 자격의 전체 범위 충족을 뜻하지 않습니다.

럭비 지식을 차분히 복습하는 흐름

자신의 속도로 연습

시간제한 없는 20문항 연습에서 답안을 확인한 뒤 해설을 읽습니다.

필요한 문항 다시 보기

문항을 북마크하고 저장한 자료와 기기 내 학습 진도를 확인합니다.

선택한 주제 공부

어린 연령대 경기의 판단, 공정한 참여, 세션 준비와 성찰을 공부합니다. 지식 연습이며 코칭 세션 계획 도구가 아닙니다.

다운로드 시 결제하는 앱으로 오프라인 학습 자료를 포함하며 구독이나 앱 내 콘텐츠 잠금 해제 결제가 없습니다. 외부 출처 링크는 인터넷이 필요합니다. 등록·교육·평가 비용은 별도입니다.

출처 안내

이 독립 학습 앱은 일부 주제만 다룹니다. 실제 자격 요건에는 실무 계획·진행·성찰과 학습자 자료 과제가 포함됩니다. 실제 활동 전에 기관의 최신 연령별 규칙과 요구 사항을 확인하세요.

RFL Level 1 코칭 과정

RushLabs의 독립 소프트웨어이며 Rugby Football League 또는 Qualsafe Awards와 제휴하거나 해당 기관의 후원·승인을 받지 않았습니다. 연습 문항은 공식 시험지가 아닙니다.
