Confidentialité du site

Ce site ne comporte ni formulaires, comptes, publicité, scripts d’analyse, cookies de suivi ou stockage du navigateur. Les langues utilisent des liens ordinaires.

Ce site est hébergé sur GitHub Pages. GitHub traite les requêtes d’hébergement selon sa propre politique de confidentialité, distincte des fonctions du site.

Ce site est distinct de l’application. Sa politique existante est liée ci‑dessous. Cette page ne remplace pas la déclaration App Store et n’établit pas le comportement réseau du binaire final.
